# Fanpage Karma Batch Provenance Log

Use this file to document each external classified batch and its traceability.

## Required fields per batch
- batch_id
- original filename
- storage path
- source family (Fanpage Karma / YouScan / other)
- covered period
- ingestion date
- file hash (sha256)
- canonical/provisional decision
- reconciliation notes
- known anomalies (including Sudeste checks)
